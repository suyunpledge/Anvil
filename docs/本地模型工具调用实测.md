## 安装版验证

三个主测模型均在安装版的聊天窗口完成了一次真实文件编辑。分别检查了预览行号、确认前的磁盘内容、应用后的完整文本，以及撤销后逐字恢复的原文。项目的 27 项回归测试全部通过。

## 复测

从项目目录执行以下命令。模型标签需事先安装到本机 Ollama。

```powershell
npm run bench:chat -- qwen2.5-coder:7b deepseek-coder:6.7b fableforge-ai/mythos-v2-8b:q4_k_m
```

脚本对合成源码调用聊天后端，逐题输出 JSON，包含是否通过、动作序列、推理次数、耗时及失败详情。温度为 0，每题最多 5 轮、150 秒。Qwen 和 Mythos 使用 8192 上下文；DeepSeek 短输入使用 4096，较长输入使用 8192。

此表记录每个版本、每个标签在最终对照中的一次运行。样例也用于开发适配；冷加载、量化以及重复运行可能影响结果。使用前仍需审阅文件、行号和替换内容。
