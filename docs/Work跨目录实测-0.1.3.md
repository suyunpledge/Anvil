只读题逐条比较命中的相对路径。移动题核对整批来源和目标，预览后比较文件树快照，执行后逐份比对文件，再从新的历史管理器一次撤销并比对原始文件树。冲突题单独核对整棵目录树没有变化。

明确写出的路径、文件名和扩展名由本地清单核对。Qwen3.5 优先使用 Ollama 原生工具，Mythos 使用约束 JSON。超过 120 个文件时，筛选在本地执行，模型无需接收整棵树。

在项目目录复测：

```powershell
npm run bench:work -- anvil-qwen3.5:9b fableforge-ai/mythos-v2-8b:q4_k_m fableforge-ai/mythos-v2-8b:latest
```
